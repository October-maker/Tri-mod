# Triangle mod

[点击此处查看中文版](./README.md)

## Overview
This module is built from JSON and supplemented with Java instances; it is based on the original Serpulo mainline,and it expands the campaign of Serpulo
\
In this module, Sharded (hereinafter referred to as PL) receives a public signal with an unknown signature and certificate during its conquests: it claims to be a response to the signal released by PL, expressing a desire to establish diplomatic relations with the faction where PL is located and attaching a database link as a gesture of goodwill. Players will continue to serve as PL, suppressing hostile factions, and use the content of the database to venture into space

### How to play a mod campaign
After clearing the original "biomassFacility", the mod campaign will appear in the technology tree
The module campaign is not solely attached to a single original Serpulo map. If you find that you cannot progress in the campaign, please try advancing the original campaign progress

### Regarding module compatibility
This module is currently only compatible with [TooManyItems] [TooManyItems](https://github.com/EB-wilson/TooManyItems).\
If you need to load other modules, please exercise caution. If any abnormalities occur, please refer to the entry titled "[Abnormalities caused by mixing multiple modules](https://github.com/October-maker/Tri-mod/blob/main/README_EN.md#abnormalities-caused-by-mixing-multiple-mods)"
#### Abnormalities caused by mixing multiple mods
If the game crashes or malfunctions after loading auxiliary mods (such as time acceleration mods), please consider uninstalling or replacing the conflicting auxiliary mods.

It is not recommended to mix this mod with other large content expansion mods.

At the code level, modifications may be made to the same original instance, and the consequences once this occurs cannot be predicted.
From the perspective of numerical balance, the balance system of one mod is usually not applicable to other mods, which can seriously ruin the gaming experience.

In summary, exercise caution when mixing this mod with other large content expansion mods.
#### Regarding the modified clients based on the original MindustryX and others
Currently, the mod supports running on MindustryX, but unknown bugs may occur on other modified clients.
