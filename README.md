## 总览
本模组源于json并辅以Java实例构建而成；整体基于原版Serpulo主线创作；为Serpulo的战役进行拓展
\
在本模组中，Sharded（此后称PL）在攻城略地时接收到了未知签名与证书的公开信号：其声称是对PL所释放信号的回应，期望与PL所在势力建交并附上一份数据库链接用以表达诚意。玩家将继续作为PL清剿敌对势力，并借助数据库内容进入太空

## 问答
当你发现问题或感到困惑时，请检查模组版本是否为最新版本
### 如何游玩模组战役
通关原版区块“生物质合成区”后，模组战役将出现于科技树后
模组战役并非仅挂载于一个原版Serpulo地图后，如发现无法推进战役请尝试推进原版战役进度
### 关于Erekir
目前规划中无Erekir相关更新内容
### 关于新建星球
目前规划中，新星球的发布通常是由于新体系的出现，且规划中有明确的新星球创建需求，敬请期待后续更新
### 关于异常处理
如果加载模组后出现异常，可以在github页面提交issue或加入模组交流群（469358412）反馈报错内容
记得附上报错文本，如找得到崩溃日志也请一并上传（其存储在游戏文件夹下的crashes文件夹中），否则作者和群友们除了给你算一卦以外什么都做不了(#｀-_ゝ-)
### 关于模组适配性
本模组目前仅适配了 [TooManyItems](https://github.com/EB-wilson/TooManyItems)
如需加载其它模组，请慎重，如出现异常，请查看条目“关于多模组混搭造成的异常”
#### 关于多模组混搭造成的异常
如加载辅助模组（诸如时间加速类模组）后游戏崩溃或出现异常，请考虑卸载或替换冲突的辅助模组

不建议将该模组与其他大型内容拓展模组混搭

从代码层面上，可能出现对同一原版实例进行修改的内容，发生后所造成的结果无法预估
从数值平衡层面上，一个模组的平衡体系通常不适用于其他模组，这会严重破坏游玩体验

综上所述，将本模组与其他大型内容拓展模组混搭时请慎重
#### 关于X端等原版改端
目前模组支持在X端上运行，其他改端可能出现未知的bug
### 关于灵感来源
其实有很多内容不完全出自于作者本人，例如工业线的设计在很多地方都参考了现实中的实现方法；以及多配方工厂的一些功能，也是在看到了优秀作品后念叨着“这功能好啊，我也要做”然后打开idea······所幸有一个喜爱的游戏，有诸多优秀的同僚们，能容下这个小小模组的广阔社区
无论如何，作者是绝对不会说“这些都是我的原创想法”，这很邪恶
